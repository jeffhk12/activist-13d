Machine learning for 13D investment selection

Jeff Lu | ML professor project and progress report | 21 October 2026

Research question: can information available after an initial Schedule 13D disclosure improve predictions of subsequent stock performance relative to a size-appropriate benchmark? Does separately validated information extracted from filing text improve the same models?

Current finding. The first small neural network and tree comparisons have been trained and evaluated. None improves pooled return-prediction error over the simple references on the same 302 later events. The neural network also has negative within-year rank correlations in all three years. This is a negative development result, with useful next diagnostic questions; no investment edge is established.

The neural network remains the central class method. Ridge regression and tree methods provide comparisons. LLM extraction is a planned feature-construction extension, rather than the core prediction model.

What the network receives

Within each year, learn transformations on training inputs only: declared log(1+x) transforms; median replacement for missing numerical values; missing-value indicators; numerical centering and scaling; industry indicator columns; and removal of training-constant columns. Reuse those fitted transformations on later entries. Unseen later industries use an all-zero industry vector and are separately flagged in diagnostics.

The ten fields become 51, 63 and 69 retained input columns for 2021, 2022 and 2023. In 2023 these are eight varying numerical columns, three missingness columns and 58 industry indicators. The header reporter count is constant in training and drops out. [E2]

Excluded from inputs: raw issuer/reporter IDs, HFR labels, future returns or amendments, Bloomberg financials and LLM interpretations. Momentum, volatility and liquidity predictors are not assembled in this version. Prior-disclosure histories begin with the supplied archive in 2013.

The small neural network: what was trained

The network learns four intermediate combinations of the prepared inputs, then combines them into one continuous return forecast. It has one hidden layer of width four and a linear output, allowing positive and negative predictions. [E4]

Architecture: prepared inputs (51 / 63 / 69) → four fully connected ReLU hidden neurons → one linear return output.

For neuron j: z_j = sum_k(W_jk x_k) + b_j; activation h_j = max(0, z_j).
Final forecast: yhat = c + sum_j(v_j h_j). Weights W and v determine sensitivity; biases b and c shift the responses. Training learns them jointly.

Why ReLU? It introduces bends into the prediction rule. Without a nonlinear activation, successive affine layers collapse to another affine rule. For an invented ownership example, max(0, ownership - 8) is inactive below 8% and increases above it. Our actual thresholds and input combinations are learned, not set to 8%. A neuron is not assumed to have an economic interpretation.

How learning updates the weights

A forward pass computes forecasts. The training objective measures mean squared error plus a penalty on large weights. Backpropagation computes how that objective changes with each parameter; Adam uses those gradients to update the parameters. More parameters increase flexibility, rather than guaranteeing better prediction.

Fixed training objective: mean((yhat - y)^2) + 0.01 x (sum(W^2) + sum(v^2)). Both biases are unpenalized. Targets stay in decimal return units without clipping, scaling or transformation.

Initialization: hidden weights use a normal distribution with standard deviation sqrt(2/p), hidden biases start at zero, output weights have standard deviation 0.01, and the output bias starts at the training-target mean. Training uses 500 full-batch Adam updates at learning rate 0.001; the final update is always used. No later-year early stopping. [E4]

Five fixed seeds (11, 23, 37, 51, 71) give five starting-weight choices. All five forecasts are averaged for the main network result; each seed remains reported. PyTorch CPU float64 fitting ran on Windows. A fixed 500-update budget does not prove convergence.

Comparison methods and chronological evaluation

All methods receive identical prepared inputs and are scored on identical later events. Configurations are fixed starting choices, with no hyperparameter search. This compares these implementations; it is not an optimized ranking of algorithm families. [E3-E4]

Target and information timing

Target y is the cumulative stock total return minus its assigned Russell size-segment ETF-proxy cumulative return over 504 exchange sessions. Entry is the opening of the second exchange session after public acceptance, with entry counted as session one. This is an event-level gross return difference, not annualized or risk-adjusted alpha. Historical index/size assignment and ETF-proxy returns are distinct concepts. [E3]

How forecast errors are calculated

e_i = prediction_i - actual_i; MAE = sum(abs(e_i))/n; RMSE = sqrt(sum(e_i^2)/n). Pool all 302 event errors with equal event weights. Do not average yearly RMSE. Multiply decimal error measures by 100 to report percentage points. Weight penalties are excluded from evaluation errors.

Invented arithmetic: errors of +10, -10 and +30 points give MAE = 50/3 = 16.67 points and RMSE = sqrt(1,100/3) = 19.15 points. Opposite signs cannot cancel in either measure; squaring makes a 30-point miss count nine times as much as a 10-point miss.

All outcome history was already examined in earlier project work. These are chronological development evaluations, not an untouched final test. Neither chronological separation nor reproducibility creates independent observations.

Results: forecast accuracy, ranking and stability

No tested feature-based model beats the earlier-training mean or zero-excess reference on pooled RMSE. The same is true for pooled MAE. The forest improves RMSE modestly over ridge (92.42 vs 93.68 points), but remains worse than both constants. This does not demonstrate useful incremental prediction. [E5]

Can the model rank opportunities despite inaccurate magnitudes?

Spearman correlation compares the ordering of predictions with the ordering of actual returns within each year. +1 means identical ordering, 0 means zero rank correlation, and -1 means reversed ordering. Constant references have no within-year ranking. This descriptive measure does not establish an investable portfolio.

Feature extensions, limitations and research controls

Structured-data learning is the completed first comparison. The next information sets should be added in separately specified experiments on comparable events, keeping the current negative result visible.

Bloomberg fundamentals: received, not yet model-ready

The returned workbook matches all 667 requested events: 587 have all nine numeric raw fields, 57 are partial and 23 have none. These counts assess completeness and internal consistency, not point-in-time correctness. [E9]

The annual-period rule uses the calendar year before the cutoff. A January 3, 2019 BHE row selects FY2018 figures announced on February 7, 2019, after the cutoff. This is a concrete information-availability conflict. Prior-year revenue, operating cash flow and company market cap are absent, and annual flows differ from the requested actual trailing-twelve-month measures. Historical mapping, publication dates, revisions, currency and scale need validation. No Bloomberg fields entered the completed models.

LLM extraction: secondary information contribution

The proposed role is to convert filing passages into structured inputs, such as stated governance objectives, capital-allocation demands and ownership relationships. Deterministic processing supplies explicit dates, identifiers and source rows; LLM interpretation addresses language and attribution that fixed parsing may miss. No incremental LLM performance result exists. [E10]

Limits that matter for interpretation

Data: return/benchmark coverage selects the population; ownership and investor identity remain uncertain; dated vendor history does not certify original availability. The inherited non-overlap rule can remove informative ML examples and requires a separate design decision.

Statistics: 118-365 training events are small relative to 213-285 neural parameters. Return windows overlap and identities recur. Squared error emphasizes extreme targets. No confidence intervals, causal findings or independent-event significance claims are reported.

Decision scope: the current outcome is a two-year return forecast. Invest/not-invest, entry timing, holding horizon and position sizing remain separate policy choices requiring capital, cost and risk assumptions. No funded portfolio, after-cost alpha or live trading is evaluated.
