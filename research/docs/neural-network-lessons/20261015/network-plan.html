Plan for our first small neural network

15 October 2026 | Checkpoint 4 teaching and proposed design | Not a frozen experiment or fitted model

Question: does a small network's learned nonlinear combinations of the existing filing inputs improve later-year predictions compared with the fixed ridge, training-mean and zero-excess references? This is a proposed first specification, not a claim that four neurons or these training settings are optimal.

The network

Prepared inputs → four ReLU hidden neurons → one linear return output. Each hidden neuron receives all prepared inputs and learns its own weights and bias. Each applies ReLU to its weighted sum. The output combines the four hidden signals with learned weights and a bias. The output is linear so benchmark-relative forecasts can be negative.

Width means four hidden neurons. Depth means one hidden layer; the output is a second parameterized layer. Input encoding is reused from checkpoint 2, not learned anew using future events. Ten original fields become 51, 63 or 69 numerical columns because industries are encoded into binary columns and missingness flags are included.

Parameter count = 4p input weights + 4 hidden biases + 4 output weights + 1 output bias = 4p + 9. These counts follow directly from the proposed architecture. Four hidden neurons is small in structure, but still flexible relative to our sample, especially in 2021. Parameter count alone does not establish generalization; regularization and later-year evaluation remain necessary.

What we will learn and build, in order

  1. Forward pass: use a tiny invented example to compute hidden weighted sums, ReLU activations and the final forecast. Verify the parameter count and tensor dimensions.
  2. Loss: compare the forecast with its known target, calculate squared error, then add the declared weight penalty. Explain why the very large historical return targets can dominate squared errors. Do not silently trim or change targets.
  3. Backward pass: calculate how a small change to an output weight, hidden weight or bias changes the loss. Work through a hand calculation before using automatic differentiation for the real model.
  4. Update: distinguish derivative calculation from the optimizer's update. Show a simple gradient step first, then explain what Adam adds. Check derivatives numerically and test the implementation on synthetic data.
  5. Freeze and fit: settle the implementation environment and freeze architecture, exact objective, initialization, seeds, update budget, numerical precision and reporting rules before fitting the real experiment. Pin dependencies and record source hashes. The proposed implementation is PyTorch with automatic differentiation; it is not installed in the current project environment and no installation occurs in this planning step.
  6. Interpret: persist forecasts before scoring the same 302 later entries. Compare errors and within-year rankings with checkpoint 3, show each year and seed, and inspect inactive hidden neurons and training diagnostics. A favorable seed is not a selected result.

Evaluation and limits

Retain all covered investor groups, including other/unresolved; HFR categories and issuer/reporter IDs remain diagnostics. Reuse the same input preparations, inherited observation rules, two-year stock-minus-Russell ETF-proxy target and January training cutoffs. Training outcomes must have finished before the cutoff. Previously inspected history remains development data, not a new untouched test.

Report RMSE and MAE in percentage points, within-year Spearman correlations, the predeclared ensemble and individual-seed results. Evaluate the same rows as the saved ridge comparisons. Checkpoint 3 has training-mean RMSE 89.90 pp, zero-excess RMSE 87.08 pp and fixed-ridge RMSE 93.68 pp across 302 later events. Neural settings and ridge settings differ; a comparison of these fixed specifications would not isolate architecture as the sole cause of any difference.

Large targets, sparse industry inputs, missing ownership, overlapping outcomes and repeated identities remain limitations. Record training failures or inactive neurons rather than choosing seeds because later results improve. If training is numerically invalid, preserve the refusal and revise code/protocol in a separate identified version. Improvements to loss functions or target transforms are separate experiments with disclosed outcome awareness.

LLM ownership and intent additions follow the first deterministic-feature neural comparison and their own source-based validation. Investment sizing, timing, horizon optimization and portfolio performance remain later work. The first network is a testable research method, not a proven alpha engine.
