Do nonlinear models improve post-13D investment selection?

October 19, 2026 · Checkpoint 4A: implementation and preparation · Actual 13D fitting reserved for Windows

We are building a controlled first comparison: the small neural network stays central to the ML class project. A shallow decision tree, random forest and gradient-boosted trees test whether other ways of learning nonlinear relationships work better on the same information. The code is checked with invented examples; this page contains no new 13D predictive result. New Bloomberg fundamentals remain excluded while historical availability is unresolved.

A leaf is a tree's final group: its prediction is based on the training outcomes in that group. Depth counts successive splits along a path. A forest's tree count is different from depth. Boosting is a family of sequential learning methods; this first implementation uses scikit-learn's conventional regression gradient boosting. XGBoost, LightGBM and CatBoost are other implementations we can examine later under a separate design. Adding more packages now would not by itself strengthen the comparison.

These models are established methods. Recency is not the criterion: later-year performance on the same information is what matters. The shallow models and minimum leaf size limit flexibility in a small sample; these fixed settings are starting hypotheses, not optimized choices.

The parameter count is 4p input weights + 4 hidden biases + 4 output weights + 1 output bias = 4p+9. The training groups overlap across years, so their counts must not be added as unique events. The 302 later entry rows are distinct; their two-year return windows overlap.

  • Starting weights: different random draws break symmetry between neurons. Hidden weights have variance 2/p; hidden biases start at zero. Output weights start small and the output bias starts at the matured training-target mean.
  • Activation: ReLU keeps positive weighted sums and sets negative ones to zero. Different learned weights and biases produce different boundaries. A neuron is not a single preselected investment ratio.
  • Loss: average squared prediction error plus 0.01 times squared weights, with no penalty on biases. The penalty is regularization: it discourages large weights that may fit historical noise.
  • Backward pass: calculate how each weight and bias changes the loss. PyTorch's automatic differentiation performs these chain-rule calculations; our tests independently check the derivatives.
  • Update: Adam uses the derivatives and their running history to change parameters. Learning rate 0.001 controls the update scale. Backpropagation computes the derivatives; the optimizer performs the update.
  • Duration: 500 full-batch updates. Every update uses all matured training observations in that year. We keep the final update, with no early stopping chosen from later-year errors. A fixed budget does not prove convergence.
  • Random starts: seeds 11, 23, 37, 51 and 71. Report every run and their equal-weight prediction average. We do not select the best seed after seeing returns.

A forward and backward pass you can calculate

Invented arithmetic example, not a fitted 13D result. Use two prepared inputs x=(1,2) and only two hidden neurons to make the calculation readable. The actual model has four hidden neurons and many more inputs.

Neuron 1: z1 = 0.50×1 + 0.25×2 + 0.10 = 1.10
Neuron 2: z2 = −1.00×1 + 0.50×2 − 0.20 = −0.20
ReLU: h1 = 1.10, h2 = 0
Output: prediction = 0.20×1.10 − 0.30×0 + 0.10 = 0.32
Invented actual target = 0.50; error = −0.18
Squared error = 0.0324
Weight penalty = 0.01×1.6925 = 0.016925
Total loss = 0.049325

The prediction is +32 percentage points and the invented target is +50 points because returns are stored as decimals. The output's error derivative is 2×(0.32−0.50)=−0.36. Increasing the output bias slightly would therefore reduce loss. For neuron 1's output weight, the full derivative is −0.36×1.10 + 2×0.01×0.20 = −0.392. Subtracting a small multiple of that negative derivative increases this weight.

For neuron 1's first input weight, the derivative is −0.36×0.20×1 + 2×0.01×0.50 = −0.062. The chain passes through the output weight and active ReLU. Neuron 2 is inactive for this example, so its prediction-error gradient is zero here; its weights can still change because of the weight penalty or other examples in the batch. At exactly zero we use a zero ReLU derivative. This example illustrates a derivative and simple gradient direction; Adam's actual update also uses running gradient statistics.

Tree and boosting arithmetic

Separate invented example, also used in the tests: one input takes values 0,1,2,3 and corresponding targets are 0,0,2,2. A depth-one tree splits between 1 and 2. Its two leaf means are 0 and 2. A forest averaging identical trees would give the same predictions; real forest resampling and input subsampling create variation.

Boosting starts at the overall mean, 1. Its residuals—the amounts still underpredicted—are −1,−1,+1,+1. The first small tree predicts −1 for the first group and +1 for the second. With learning rate 0.5, the updated predictions are 1+0.5×(−1)=0.5 and 1+0.5×1=1.5. The next tree works on the new residuals. The real protocol uses learning rate 0.05 and 100 stages, with no later-year tuning.

What stays fixed for the comparison

The target remains cumulative stock total return minus the assigned Russell size ETF-proxy return over 504 sessions, with the inherited delayed entry at the second exchange session after public filing acceptance. Each January's training outcomes must have finished before January 1. Preprocessing is reconstructed from training rows and must exactly match the saved matrices. The later outcomes do not enter model-fitting functions, and all forecasts must be saved before evaluation scoring.

The existing training-mean, zero-excess and ridge forecasts are preserved references. RMSE and MAE are forecast errors in percentage points; lower is better. Spearman measures within-year ranking agreement. We show all years, model configurations and neural seeds. Training loss and inactive-neuron diagnostics help explain fitting, but they do not replace later-year evaluation.

The largest earlier targets can dominate squared-error fitting. The first comparison deliberately preserves the target and loss family; a robust loss or transformed target would be a separate experiment. Differently constrained models are not a pure architecture-only experiment. Reusing the same matrices helps comparison, but does not guarantee the best possible representation for every tree method.
