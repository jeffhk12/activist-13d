Can following an initial 13D disclosure improve returns?

24 September 2026 · Phase 1: checking the data · No return results yet

What we know today

We have a starting sample for the investment study, but we do not yet know whether following these managers earns better returns. Of 404 initial disclosures potentially linked to our broader manager list, 240 pass the current basic data checks. They cover 217 distinct securities. They are possible observations for further review, not 240 winning trades or 240 independently verified activist campaigns.

Think of this as reconciling the holdings and price history before running a performance attribution report. A return calculation can look precise and still be misleading if it uses the wrong stock, repeats the same opportunity, or assumes a purchase before the information was available.

The investment question and our three phases

The starting question is: if an investor bought after an initial 13D became public, would that approach improve returns? We also want to know whether identifying the manager helps distinguish better opportunities from other filings.

PhaseWhat we testWhat it would tell us
1. Simple followingBuy after the disclosure using consistent entry, holding and portfolio rules.Whether there is a useful baseline strategy before adding a predictive model.
2. Structured-data machine learningUse investor identity, company characteristics and filing facts to select opportunities.Whether those facts improve selection over simple following.
3. Add NLPAlso read the investor's stated intentions in Item 4.Whether the text adds investment value beyond the other information.

Phase 1 is not the machine learning phase. It provides the comparison that the later models need to beat.

How 75,631 records became 404 relevant initial disclosures

The archive contains 75,631 parsed filing records, including both initial disclosures and later amendments. Within it, 17,795 records are initial 13Ds. Starting with initial disclosures keeps an investor's later updates from automatically becoming repeated new entry signals.

Our broader list combines HFR Event-Driven manager candidates with seven separately selected groups, including Elliott. It links to 3,125 records in total: 404 initial disclosures and 2,721 amendments. This is the discovery sample; the manager relationships and their historical availability still need review.

The broader list contains 71 candidate manager units, including a focused activist list of 22. These are provisional identity groupings, not yet a certified count of distinct economic managers. The focused list has 323 initial disclosures within the broader 404.

The dates are not yet aligned for a fair comparison: the supplied HFR history starts in 2018, while the supplemental groups were selected retrospectively. Available current stock and price data in this audit extend through 2025; 2026 coverage remains incomplete. These counts are a coverage inventory, not a finalized performance sample period.

What the comparison can—and cannot—tell us yet

Another 7,699 initial filings outside the broader manager subset pass the same sequential basic checks. Together with the 240, that gives 7,939 preliminary observations across the archive.

That creates a possible comparison, but “outside our list” does not mean “not an activist.” It includes unrecognized and unresolved managers. We also match stocks much more often in the broader manager group: 372 of 404 initial filings, versus 9,641 of 17,391 other initial filings before applying source-integrity exclusions. The two groups' missing data could affect any apparent performance difference.

For an allocator, the relevant question is whether manager identity helps select investments after accounting for differences such as the period, company characteristics and practical trading rules. A higher unadjusted average alone would not settle that question.

What happens next

  1. Confirm who is investing and what counts as a new opportunity. Review manager relationships and repeated filings so the same position is not accidentally counted as several independent ideas.
  2. Set the return comparison before examining results. Specify a common sample period, benchmark, holding period, position weights, costs, treatment of delistings and overlapping positions. Final choices remain open.
  3. Calculate the baseline performance. Compare simple following for the identified-manager subset with other filings and the agreed benchmark, using the same trading rules. Report how much any difference is, how uncertain it is, and whether it survives costs.

The current purchase-date check uses the second trading session after the public acceptance date, allowing a full intervening session. This is a conservative data-check convention; it is not yet the final execution rule.
